# Telegram Trade Notifications

## Описание

Добавлена опциональная функция отправки красивых информативных уведомлений о сделках в Telegram с кнопкой подтверждения "ОК".

## Что изменилось

### 1. Новая ENV переменная

```env
# Включить/выключить уведомления о сделках в Telegram (по умолчанию: true)
TELEGRAM_TRADE_NOTIFICATIONS=true
```

- `true` или `1` — уведомления включены
- `false` или `0` — уведомления выключены

### 2. Формат уведомления

При создании сделки отправляется сообщение с параметрами:

```
🟢 LONG XRP

📊 Risk: $100.00
⚙️ Preset: 4h

💰 Входы:
  📌 LIMIT #1: $500.00 @ 2.35
  📌 LIMIT #2: $300.00 @ 2.33

🎯 Takes: 3R, 5R, 7R
   Распределение: 35%, 30%, 35%

[✅ ОК]
```

### 3. Типы входов

- 📌 LIMIT — лимитный ордер (ниже рынка для long, выше для short)
- 🛑 STOP — стоп-ордер (выше рынка для long, ниже для short)
- ⚡ MARKET — мгновенный вход по рынку

### 4. Обновлённый Help

Help текст полностью переработан для большей наглядности:
- Добавлены разделители секций
- Больше примеров
- Эмодзи для категорий команд
- Пояснения по суффиксам (k, m/kk)

## Использование

### Включить уведомления (по умолчанию)

В `.env`:
```env
TELEGRAM_TRADE_NOTIFICATIONS=true
```

Или просто не указывать переменную — уведомления включены по умолчанию.

### Выключить уведомления

В `.env`:
```env
TELEGRAM_TRADE_NOTIFICATIONS=false
```

### Функции

#### `formatTradeNotification(params)`

Параметры:
```typescript
{
  ticker: string;              // Символ (xrp, btc, etc)
  side: "long" | "short";      // Направление
  riskUsd: number;             // Риск в USD
  legs: Array<{                // Ноги входа
    usd: number;
    price: number;
    type: "LIMIT"|"STOP"|"MARKET";
  }>;
  takes: number[];             // TP R-множители
  takesRatio?: number[];       // Распределение в %
  preset: string;              // Название пресета
  market?: boolean;            // Маркет-вход?
}
```

Возвращает: HTML-строку для Telegram

## Безопасность

- Торговый функционал **не изменён** — если отправка уведомления падает, торговля продолжается
- Уведомление отправляется **перед** выполнением команды
- При ошибке отправки выводится только лог, команда выполняется нормально

## Обратная совместимость

✅ Полная обратная совместимость:
- Если `TELEGRAM_TRADE_NOTIFICATIONS` не указана — уведомления включены (можно отключить явно)
- Весь торговый функционал работает как прежде
- Консольный режим не затронут

## FAQ

**Q: Можно ли отключить уведомления?**  
A: Да, установите `TELEGRAM_TRADE_NOTIFICATIONS=false` в `.env`

**Q: Уведомление мешает торговле?**  
A: Нет, уведомление отправляется асинхронно, ошибка отправки не влияет на выполнение сделки

**Q: Можно ли кастомизировать формат?**  
A: Да, отредактируйте функцию `formatTradeNotification()` в `src/core/format.ts`

**Q: Работает ли в консольном режиме?**  
A: Нет, уведомления только для Telegram. Консольный режим не изменён.

**Q: Что делает кнопка "ОК"?**  
A: Просто закрывает popup подтверждения в Telegram. Это UX-элемент для удобства.
